# Start here

This kit holds everything an AI agent needs to build GlowUp Booking v1.

| File | What it's for |
|---|---|
| `CLAUDE.md` | The agent's memory and rules. Claude Code reads it automatically. |
| `docs/SUPERVISOR.md` | **For you:** how to run the build, prompts to paste, what to check. |
| `docs/ROADMAP.md` | Milestones M0–M9 with tasks and "done when" checks. |
| `docs/PROGRESS.md` | Progress tracker and handoff notes, updated by the agent. |
| `docs/PRD.md` | Requirements, business rules and user stories. |
| `docs/DESIGN.md` | Colours, statuses and which design file goes with which page. |
| `docs/DECISIONS.md` | Decisions made so far, and why. |
| `docs/TECH_STACK.md` | Each tool chosen, why, the alternatives, and when to reconsider. |
| `docs/OPEN_QUESTIONS.md` | Questions only you or the client can answer. |
| `design/screens/` | Every approved screen as an HTML reference. |

Next step: open `docs/SUPERVISOR.md`.
